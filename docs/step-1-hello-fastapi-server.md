# Step 1. Run Your First FastAPI Server

## Goal

The goal of this step is to create and run your first FastAPI server.

By the end of this step, you should be able to:

- Write a minimal FastAPI app
- Create simple API endpoints
- Run the server locally using Uvicorn
- Open the API in a browser
- Test the API using FastAPI’s built-in `/docs` page

---

## Before You Start

Make sure you completed Step 0.

Your project folder should look like this:

```text
mini-notes-server/
  README.md
  main.py
```

You should also have a Python virtual environment named `.venv`.

Before starting, open your terminal in the project folder:

```bash
cd mini-notes-server
```

Activate the virtual environment.

On Mac or Linux:

```bash
source .venv/bin/activate
```

On Windows:

```bash
.venv\Scripts\activate
```

You should see something like this in your terminal:

```text
(.venv) $
```

This means the virtual environment is active.

---

# 1. Create a Minimal FastAPI App

Open `main.py`.

Add the following code:

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/health")
def health():
    return {"status": "ok"}


@app.get("/hello")
def hello():
    return {"message": "Hello, FastAPI!"}
```

Save the file.

---

# 2. Understand the Code

Let’s walk through the code.

## Import FastAPI

```python
from fastapi import FastAPI
```

This imports the `FastAPI` class from the `fastapi` package.

We need this to create a FastAPI application.

---

## Create the app object

```python
app = FastAPI()
```

This creates the FastAPI application.

You can think of `app` as the main server application.

Later, when Uvicorn runs the server, it will look for this `app` object.

---

## Create the `/health` endpoint

```python
@app.get("/health")
def health():
    return {"status": "ok"}
```

This creates a `GET /health` endpoint.

That means when a client sends a GET request to:

```text
http://127.0.0.1:8000/health
```

FastAPI will run this Python function:

```python
def health():
    return {"status": "ok"}
```

The dictionary:

```python
{"status": "ok"}
```

will be returned as JSON.

---

## Create the `/hello` endpoint

```python
@app.get("/hello")
def hello():
    return {"message": "Hello, FastAPI!"}
```

This creates a `GET /hello` endpoint.

When a client visits:

```text
http://127.0.0.1:8000/hello
```

the server will return:

```json
{
  "message": "Hello, FastAPI!"
}
```

---

# 3. What Is an Endpoint?

An endpoint is a specific URL path that the server responds to.

In this step, we created two endpoints:

```text
GET /health
GET /hello
```

Each endpoint is connected to a Python function.

```text
/health  →  health()
/hello   →  hello()
```

So when the client requests `/hello`, FastAPI runs the `hello()` function.

---

# 4. Run the Server

In the terminal, make sure you are inside the project folder and the virtual environment is active.

Run:

```bash
uvicorn main:app --reload
```

You should see output similar to this:

```text
INFO:     Uvicorn running on http://127.0.0.1:8000
INFO:     Application startup complete.
```

This means your server is running locally.

---

# 5. Understand the Uvicorn Command

The command is:

```bash
uvicorn main:app --reload
```

Here is what each part means:

```text
uvicorn
```

Runs the Uvicorn server.

```text
main
```

Refers to the `main.py` file.

```text
app
```

Refers to the `app = FastAPI()` object inside `main.py`.

```text
--reload
```

Automatically restarts the server when you change your code.

So this command means:

```text
Run the FastAPI app named app from the main.py file,
and restart automatically when the code changes.
```

Open your browser and go to:

```text
http://127.0.0.1:8000/health
```

You should see:

```json
{
  "status": "ok"
}
```

Then open:

```text
http://127.0.0.1:8000/hello
```

You should see:

```json
{
  "message": "Hello, FastAPI!"
}
```

---

# 7. Test the API Using FastAPI Docs

FastAPI automatically creates an API documentation page.

Open:

```text
http://127.0.0.1:8000/docs
```

You should see a web page showing your API endpoints.

You should see:

```text
GET /health
GET /hello
```

Click each endpoint and try the **Try it out** button.

Then click **Execute**.

You should see the response from the server.

---

# 8. What Is `/docs`?

The `/docs` page is automatically generated by FastAPI.

It lets you test your API without writing a frontend or using another tool.

This is useful because you can:

- See all available endpoints
- Test requests
- See responses
- Understand what the API does

For now, `/docs` is one of the easiest ways to test your server.

---

# 9. Stop the Server

To stop the server, go back to the terminal and press:

```text
Ctrl + C
```

After stopping the server, try opening:

```text
http://127.0.0.1:8000/hello
```

It should no longer work.

This is an important concept:

```text
The server only responds to requests while the server program is running.
```

---

# 10. Restart the Server

Start the server again:

```bash
uvicorn main:app --reload
```

Now open:

```text
http://127.0.0.1:8000/hello
```

It should work again.

# 12. Common Problems

## Problem: `uvicorn: command not found`

This may mean Uvicorn is not installed or your virtual environment is not active.

Try:

```bash
source .venv/bin/activate
```

On Windows:

```bash
.venv\Scripts\activate
```

Then reinstall:

```bash
pip install fastapi uvicorn
```

---

## Problem: `ModuleNotFoundError: No module named 'fastapi'`

This means FastAPI is not installed in the current Python environment.

Make sure the virtual environment is active, then run:

```bash
pip install fastapi uvicorn
```

---

## Problem: Browser says the site cannot be reached

Make sure the server is running.

You should see something like this in the terminal:

```text
Uvicorn running on http://127.0.0.1:8000
```

If the server is not running, start it again:

```bash
uvicorn main:app --reload
```

---

## Problem: You changed the code but the browser did not update

Try refreshing the browser.

Also check the terminal to make sure Uvicorn restarted successfully.

If needed, stop the server with:

```text
Ctrl + C
```

Then restart it:

```bash
uvicorn main:app --reload
```

# 15. Key Ideas

The most important ideas from this step are:

```text
A FastAPI server is a Python program that waits for HTTP requests.

An endpoint is a URL path that the server responds to.

Each endpoint is connected to a Python function.

When the browser sends a request, FastAPI runs the matching function.

The function returns data, usually as JSON.

Uvicorn is used to run the FastAPI app.

The server only works while Uvicorn is running.
```
